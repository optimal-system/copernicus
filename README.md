This repository contains training materials for Copernicus API (copernicus-trainig.py)
Then there is a separation of the tools (copernicus_tools.py) and the studies (ex : copernicus_britany.py)
The tools simplify the uses of the API
The studies can concentrate on data analysis
In the studies, all variables are well documented at the beginning so it's easy to play with them.
For instance the variable 'geomap' permits to set a central point on a map and the size of the frame around it. 
Depending on the resolution of the dataset, the size of the frame must be adjusted.
Depending on the variable the values of min and max must also be adjusted
